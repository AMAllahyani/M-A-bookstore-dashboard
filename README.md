# M-A-bookstore-dashboard
What's this dashboard about?
The dashboard explores the sales made by a bookstore over one year, specifically 2023. 

Contents:
- 5 visuals, presenting various aspects of the business.
- 2 filters, by membership and by date.
- 3 cards.
-

Claude sample data, written and edited using SQL on XAMPP by me. Tables were exported manually by me to Power BI as cvs files.
